---

## 一句话定义

溪是一个 4 Agent 组织：Main（主入口）+ Research（调研）+ Builder（实现）+ Archivist（治理），以 `~/srv/xi/` 为组织资产根目录，通过 GitHub xi-org 双向同步。

---

## 目录结构

```
~/srv/xi/
├── shared/           # 组织级真相（所有 Agent 共读）
│   ├── policies/     # 宪法层（SOUL / MEMORY_POLICY / KNOWLEDGE_POLICY / OPERATING_MODEL）
│   ├── projects/     # 项目状态机（每个项目一套 PROJECT/STATUS/TASKS/DECISIONS/RISKS）
│   ├── knowledge/    # 知识治理（cards/ canon/ registry/ inbox/ sources/ parsed/）
│   ├── playbooks/    # SOP / 最佳实践（coding/ research/ ops/ recruiting/ growth/）
│   └── reports/      # 周报 / 月报
├── workspaces/       # 每个 Agent 的独立工作台
│   ├── main/         # 主入口（AGENTS/USER/TOOLS/MEMORY + memory/ active/ skills/）
│   ├── research/     # 调研 Agent
│   ├── builder/      # 实现 Agent
│   └── archivist/    # 治理 Agent
└── scripts/          # 同步脚本
```

---

## 4 Agent 分工

| Agent | 职责 | 不做 |
|-------|------|------|
| Main | 主入口、目标理解、分派、汇总 | 大规模调研/实现/归档 |
| Research | 外部调研、最佳实践、方案对比 | 改代码、定战略 |
| Builder | 代码实现、配置、脚本、MVP | 改战略、大重构 |
| Archivist | 记忆治理、知识清洗、周报月报 | 定目标、改代码 |

---

## 同步机制

- Mac：`~/srv/xi/` → 每 10 分钟 push 到 GitHub xi-org
- 服务器：每 10 分钟从 xi-org pull
- 配置：`~/Library/Application Support/QClaw/openclaw/config/openclaw.json` 中 `workspace: "~/srv/xi/workspaces/main"`

---

## token 成本基线

| 分派深度 | 典型消耗 |
|---------|---------|
| Main 直接回答 | 5-10k |
| 1 个子 Agent | 30-40k |
| 2 个子 Agent | 50-70k |

---

## 关键决策

1. 组织资产与 OpenClaw 运行时分离（`/srv/xi/` vs `~/.openclaw/`）
2. 每个 Agent 独立 workspace，shared/ 做单源真相
3. 分派阈值：任务复杂度 > 15k tokens 才值得分派
