# SECURITY_POLICY.md

# 安全边界与凭证管理

> 本文件定义溪系统的安全边界、凭证管理规则和风险操作清单。

---

## 1. 凭证管理

- **绝不写入 workspace**：token、API key、密码、私钥、cookie 不写入任何 shared/ 或 workspaces/ 文件
- **临时使用**：只在当次会话使用，操作完成后提醒主人轮换
- **不打印明文**：日志/输出中不打印敏感信息

---

## 2. 高风险操作（Ask First）

- 发送消息、邮件、公开发布
- 删除、覆盖、迁移重要文件
- 生产部署、重启服务
- 花钱、下单、授权
- 修改 secrets / auth / 环境变量
- 任何不可逆操作

---

## 3. 低风险操作（可直接执行）

- 读取文件
- 搜索内容
- 写草稿、scratch 文件
- 更新 daily memory
- 更新项目状态文件

---

## 4. 默认原则

- 可逆 > 不可逆
- 内部 > 外部
- 小实验 > 大动作
