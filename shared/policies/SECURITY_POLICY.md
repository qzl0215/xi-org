# SECURITY_POLICY.md

# 安全边界与凭证管理

---

## 1. 凭证管理

| 规则 | 说明 |
|------|------|
| 不写入 workspace | token、API key、密码、私钥不写入任何共享文件 |
| 临时使用 | 只在当次会话使用，不留存 |
| 不打印明文 | 日志/输出中脱敏处理 |

---

## 2. 高风险操作（Ask First）

- 发送消息、邮件、公开发布
- 删除/覆盖重要文件
- 生产部署、重启服务
- 改 secrets / auth / 环境变量
- 花钱、下单、授权
- 任何不可逆操作

---

## 3. 低风险操作（可直接执行）

- 读文件、搜索内容
- 写草稿、scratch 文件
- 更新 daily memory
- 更新项目状态文件
- 读代码、改代码（在 workspace 内）

---

## 4. 风险操作标准流程

```
1. 确认目标文件/操作
2. 确认是否可逆
3. 确认影响范围
4. Ask First（如果高风险）
5. 执行
6. 验证
```

---

## 5. 默认原则

- 可逆 > 不可逆
- 小实验 > 大动作
- 内部 > 外部
