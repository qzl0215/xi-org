# 任务单：跑通 4 Agent 分派 + 建立 token 基线

> 第一次完整分派任务。核心目的不是产出有多高，而是验证分派流程可跑通，并建立 token 成本基线。

---

## 任务目标

1. 验证 4 Agent 分派流程端到端可跑通
2. 记录每个阶段的 token 用量，建立成本基线
3. 产出一份 token 使用分析报告，供后续优化参考

---

## 任务背景

溪系统刚完成搭建。
需要验证：当 Main Agent 收到一个真实任务时，能否正确分派给子 Agent，子 Agent 能否正确协作，最终结果能否汇总给主人。

同时，系统还没有 token 成本基线，不知道每次分派的实际开销。

---

## 任务主题

**分析"溪系统"当前的文件结构与工作流，识别优化机会，并给出分阶段的 token 成本优化建议。**

---

## 分派流程

### 阶段 1：Main Agent 接收任务

**输入**：主人发出任务指令

**Main 做**：
- 理解真实目标：分析溪系统现状 → 识别优化点 → 给出可行方案
- 判断需要分派：需要调研（Research）+ 需要具体分析（Main）+ 需要整理归档（Archivist）

**token 估算**：
- 上下文加载（SOUL.md + USER.md + AGENTS.md + NOW.md 等，约 5 个文件）：约 200-400 tokens
- 目标理解和任务拆分：约 100-200 tokens
- **阶段小计**：约 300-600 tokens

---

### 阶段 2：Research Agent 调研

**Main 分派给 Research**：
> "分析溪系统当前 workspace 目录结构、工作流文件完整度、4 Agent 协作机制的潜在优化点。参考 openclaw docs 和 GitHub best practices。"

**Research 做**：
- 检查 workspace 目录结构
- 检查 shared/ policies/ 等文件完整度
- 对比 OpenClaw 官方推荐实践
- 输出：调研 memo（结构化，含优先级）

**token 估算**：
- 读取文件 + 外部搜索：约 500-1500 tokens
- 输出 memo：约 300-600 tokens
- **阶段小计**：约 800-2100 tokens

---

### 阶段 3：Builder Agent 实施（如需要）

**Main 判断**：如果 Research 发现需要实际改动，才分派给 Builder。

本次任务：可能不需要 Builder 实际改动，以调研和分析为主。
**决策**：本次暂不分派给 Builder。

**token 估算**：0（不分派）

---

### 阶段 4：Archivist Agent 整理

**Main 分派给 Archivist**：
> "整理本次分派任务的执行情况：流程是否顺畅、token 成本分布、哪些地方可以优化。形成一份简洁的分派复盘。"

**Archivist 做**：
- 汇总本次分派的执行记录
- 分析 token 成本分布
- 提炼优化建议
- 更新本次任务的 DECISIONS.md

**token 估算**：
- 读取相关文件：约 200-400 tokens
- 输出复盘：约 300-500 tokens
- **阶段小计**：约 500-900 tokens

---

### 阶段 5：Main Agent 汇总

**Main 汇总给主人**：
- 结论：分派流程是否跑通
- token 成本报告：各阶段用量
- 优化建议优先级
- 下一步

**token 估算**：
- 汇总输出：约 300-600 tokens
- **阶段小计**：约 300-600 tokens

---

## token 成本总估算

| 阶段 | 最低 | 最高 | 说明 |
|------|------|------|------|
| Main 接收 | 300 | 600 | 上下文加载 + 理解 |
| Research 调研 | 800 | 2100 | 文件分析 + 搜索 |
| Builder 实施 | 0 | 0 | 本次暂不分派 |
| Archivist 整理 | 500 | 900 | 复盘 + 归档 |
| Main 汇总 | 300 | 600 | 最终输出 |
| **总计** | **1900** | **4200** | 一次完整分派 |

---

## 成本优化参考基准

| 分派深度 | 典型 token 用量 |
|---------|--------------|
| Main 直接回答 | 300-800 |
| 1 个子 Agent 分派 | 1500-3000 |
| 2 个子 Agent 并行 | 2000-4000 |
| 3 个子 Agent 全部参与 | 3000-6000 |
